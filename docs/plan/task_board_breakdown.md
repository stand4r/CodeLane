## 3. Параллельность и пересечения

Можно выполнять параллельно (разные файлы и символы):
- **T2** (только `docs/acceptance/*.md`, чтение `services/team_cache.py`, `core/job_recovery.py`, тестов);
- **T3** (только `widgets/AIAgentPanel.py`, `widgets/AgentTeamTab.py`, `tests/test_ai_and_scale.py`).

Пересечения и зависимость:
- **T2 ↔ T3 пересечений по файлам нет**: общих изменяемых путей не обнаружено; общий только чтение `tests/test_ai_and_scale.py`-подобных тестов команды.

- **T1 зависит от T2 и T3** (`depends_on: [T2, T3]`): коммит фиксирует рабочее дерево, поэтому должен идти последним. Если коммит нужен срочно, допустим вариант «T1 только для текущего среза, T2/T3 — вторым коммитом»; тогда T1 не блокируется, но `.gitignore`-решение по `diplom.*` всё равно требуется до коммита.
- **Общий риск всех трёх**: pytest отсутствует в текущем интерпретаторе, поэтому критерий «тесты зелёные» для T1/T3 не проверяется без установки зависимости.
