## 1. Введение

**CodeLane** — лёгкая и быстрая IDE для Windows, написанная на Python и PyQt6.
Интерфейс повторяет привычную логику современного воркбенча: слева — панель
активности и боковая панель, в центре — вкладки редактора, снизу — панель
инструментов, сверху — собственное меню и панель вкладок.

### Что внутри

| Область | Возможности |
| :-- | :-- |
| **Редактор** | Подсветка, номера строк, автодополнение, поиск/замена, мультикурсор, блоки, предпросмотр Markdown/HTML |
| **Навигация** | Быстрый переход к файлу, палитра команд, поиск по проекту, переход к строке |
| **ИИ** | Чат с моделью, инструменты чтения и правки, выполнение команд, MCP, отложенные задачи |
| **Анализ** | Карта модулей и функций проекта, метрики, отчёт о качестве кода |
| **Разработка** | Встроенный терминал, запуск и отладка проектов, Git и GitHub, СУБД, браузер |
| **Прочее** | Задачи To Do, запуск тестов, расширения, просмотр PDF, Markdown, таблиц и Hex |

> [!TIP]
> Если вы раньше работали в VS Code, большинство привычных сочетаний клавиш
> сохранится: `Ctrl+P`, `Ctrl+Shift+P`, `Ctrl+S`, `Ctrl+W`, `F5`.

## 2. Установка и запуск

### 2.1. Требования

- **Windows 10/11**
- **Python 3.11+**
- Зависимости из `requirements.txt` (PyQt6, psutil, ansi2html, asyncssh и др.)

### 2.2. Запуск из исходников

```bat
git clone https://github.com/<owner>/CodeLane.git
cd CodeLane
python -m pip install -r requirements.txt
python main.py
```

Для запуска без окна консоли используйте `CodeLane.vbs`.

### 2.3. Сборка exe и установщика

```bat
build_exe.bat
```

- `CodeLane.spec` — конфигурация PyInstaller;
- `installer/` — скрипты и ресурсы инсталлятора;
- `installer_output/` — готовый установочный пакет.

> [!NOTE]
> Готовые сборки публикуются в GitHub Releases. Приложение умеет проверять
> обновления автоматически (см. [раздел 19](#19-обновление)).

## 3. Первый запуск

При старте открывается **приветственная вкладка** с тремя карточками действий:

1. **Открыть проект** — выбрать папку проекта.
2. **Новый файл** — создать файл в редакторе.
3. **Открыть файл** — открыть существующий файл.

Ниже показывается список **недавних проектов**; у каждого проекта в контекстном
меню доступны «Открыть проект» и «Удалить из недавних».

Полезные настройки поведения при старте (вкладка **Настройки**):

| Настройка | По умолчанию | Что делает |
| :-- | :--: | :-- |
| `show_welcome` | ✅ | Показывать приветственную вкладку |
| `project_restore_last` | ✅ | Восстанавливать последний проект |
| `project_open_readme` | ✅ | Открывать README проекта |
| `project_deduplicate_recent` | ✅ | Убирать дубликаты из недавних |
| `remember_window_geometry` | ✅ | Запоминать размер и позицию окна |
| `recent_projects_limit` | `10` | Сколько проектов хранить в истории |

## 4. Обзор интерфейса

```text
┌──────────────────────────────────────────────────────────────┐
│ Меню: Файл · Правка · Проект · Вид · Запуск · Git · ИИ · …   │
├──────┬───────────────────────┬───────────────────────────────┤
│ Пан. │ Боковая панель        │ Редактор (вкладки)            │
│      │                       │                               │
├──────┼───────────────────────┴───────────────────────────────┤
│      │ Нижняя панель: Терминал · Проблемы · Тесты · Задачи   │
└──────┴───────────────────────────────────────────────────────┘
```

### Панель активности

| Иконка | Панель | Назначение |
| :--: | :-- | :-- |
| 📁 | **Проводник** | Дерево файлов проекта, создание, переименование, удаление |
| 🔍 | **Поиск** | Поиск по содержимому файлов проекта |
| 🌿 | **Git** | Статус, диффы, коммиты, ветки, GitHub |
| ✅ | **To Do** | Список задач проекта и личных задач |
| 🧠 | **Анализ проекта** | Карта модулей, метрики, здоровье кодовой базы |
| 🌐 | **Браузер** | Веб-вкладки, профили и поиск |
| ⌨ | **Терминал** | Встроенный терминал |
| ⚙ | **Настройки** | Единая страница настроек |

### Строка меню

- **Файл** — создание файла, проекта и файла подключения к БД, открытие
  файла/проекта, сохранение (в том числе как UTF-8), закрытие вкладки, выход.
- **Правка** — отмена/повтор, буфер обмена, поиск и замена в файле.
- **Проект** — настройки проекта, закрытие проекта, анализ и архитектурный граф.
- **Вид** — панели, разделение/объединение групп редактора, масштаб интерфейса.
- **Запуск** — запуск текущего файла, проекта, тестов и выделенного фрагмента.
- **Git / GitHub** — статус, коммит, ветки, клонирование, публикация, аккаунт.
- **ИИ** — чат с агентом, объяснение выделенного кода.
- **Инструменты** — рабочая среда (настройки, браузер, интеграция с оболочкой)
  и действия ИИ-агента.
- **Справка** — руководство, горячие клавиши, проверка обновлений,
  сообщение о проблеме, отправка лога.

> [!TIP]
> Меню собраны декларативно в `app/top_bar.py`, поэтому все действия из меню
> дублируются в **палитре команд** (`Ctrl+Shift+P`).

### Шаблоны новых файлов

При создании файла — через `Ctrl+N`, меню **Файл → Новый файл** или контекстное
меню проводника — CodeLane предлагает шаблон:

| Шаблон | Что создаётся |
| :-- | :-- |
| **Python-модуль** | docstring по стилю проекта, `__all__`, точка входа `run()` |
| **Qt-виджет** | `QWidget` с базовой раскладкой и заголовком |
| **Тест pytest** | каркас теста с путём проекта в `sys.path` |
| **README** | Markdown-заготовка описания проекта |
| **Без шаблона** | пустой файл (прежнее поведение) |

В правой части диалога показан предпросмотр уже подставленного текста, поэтому
видно, что попадёт в файл. Подстановки: `${name}`, `${module}`, `${subject}`,
`${class_name}`, `${project}`, `${relative_path}`, `${date}`, `${year}`,
`${author}`; автор берётся из `git config user.name`, иначе из имени
пользователя ОС.

Шаблоны хранятся в `<проект>/.codelane/templates/*.json` и создаются там
автоматически при первом обращении. Файл шаблона — обычный JSON:

```json
{
  "id": "my-module",
  "title": "Мой модуль",
  "description": "Каркас внутреннего модуля",
  "extension": ".py",
  "body": "\"\"\"${project}: ${name}\"\"\"\n"
}
```

Правьте эти файлы вручную — изменения сразу видны в диалоге; удалённый
шаблон восстанавливается из встроенного набора. Если проект не открыт,
показываются только встроенные шаблоны и ничего не создаётся на диске.
Код: `core/file_templates.py`, диалог — `widgets/FileTemplateDialog.py`.

### Масштаб интерфейса

| Действие | Сочетание |
| :-- | :--: |
| Увеличить | `Ctrl+Alt+=` |
| Уменьшить | `Ctrl+Alt+-` |
| Сбросить до 100% | `Ctrl+Alt+0` |

Масштаб применяется ко всему интерфейсу (шрифты, отступы, иконки) и реализован
в `app/ui_scale.py`.

## 5. Редактор кода

Редактор построен на `QPlainTextEdit` (`widgets/QCodeEditor.py`) и поддерживает:

- **подсветку синтаксиса** для языков из списка `languages` в настройках
  (Python, C/C++, C#, Go, Rust, Java, JS/TS, HTML/CSS, SQL, JSON, YAML, Markdown и др.);
- **нумерацию строк** (`show_line_numbers`);
- **автодополнение** на основе слов документа и языка;
- **поиск и замену** через панель `FindReplaceBar`;
- **мультикурсор** — выделение следующего вхождения (`Ctrl+D`);
- **операции со строками**: удалить (`Ctrl+Shift+K`), дублировать вверх/вниз
  (`Shift+Alt+↑/↓`), отступ/снятие отступа (`Tab` / `Shift+Tab`);
- **перенос строк** (`word_wrap`);
- **автосохранение** с настраиваемым интервалом (`auto_save_interval`, по умолчанию 30 с);
- **форматирование при сохранении** (`format_on_save`);
- **предпросмотр Markdown и HTML** (`Ctrl+Shift+V`).

### Полезные параметры

| Ключ настройки | По умолчанию | Описание |
| :-- | :--: | :-- |
| `fontsize` | `9` | Базовый размер шрифта |
| `show_line_numbers` | ✅ | Номера строк |
| `syntax_highlighting` | ✅ | Подсветка синтаксиса |
| `word_wrap` | ❌ | Перенос длинных строк |
| `auto_save_interval` | `30` | Интервал автосохранения, сек |
| `format_on_save` | ❌ | Форматировать при сохранении |
| `restore_session` | ❌ | Восстанавливать открытые вкладки |

> [!NOTE]
> Файлы сохраняются в UTF-8. Для явного сохранения в UTF-8 используйте
> **Файл → Сохранить как UTF-8…**.

## 6. Навигация и поиск

### Быстрый переход к файлу — `Ctrl+P`

Начните вводить имя файла — CodeLane найдёт его по индексу рабочей папки.

### Палитра команд — `Ctrl+Shift+P`

Единая точка входа ко всем действиям: открыть файл, сохранить всё,
переключить тему, открыть панель, запустить проект и т. д.

Примеры команд:

```text
Файл: Новый файл
Файл: Открыть файл
Файл: Сохранить всё
Файл: Открыть в HEX-просмотрщике…
Файл: Открыть как таблицу…
```

### Поиск по проекту

Панель **Поиск** в панели активности ищет по содержимому файлов с учётом
исключений проекта (`.git`, `__pycache__`, `dist` и т. п.).

### Поиск в редакторе

- `Ctrl+F` — найти;
- `Ctrl+H` — заменить;
- `Esc` — закрыть панель поиска.

## 7. ИИ-агент

ИИ-агент — это чат, который не только отвечает, но и **действует в проекте**:
читает файлы, ищет код, применяет патчи, запускает команды и тесты.

### Голосовое управление

В панели агента нажмите кнопку микрофона, произнесите фразу и дождитесь распознавания
(до 8 секунд). Команды «Джарвис, открой настройки», «запусти файл»,
«сохрани файл», «новый файл», «открой файл», «покажи терминал»,
«скрой терминал» и «палитра команд» выполняются в CodeLane. Остальные фразы
отправляются агенту как сообщения. Озвучивание ответов включается в
**Настройки → ИИ-агент → Озвучивать ответы агента**.

Для ввода нужен микрофон, пакеты `vosk` и `sounddevice` из `requirements.txt`
и русская модель `vosk-model-small-ru-0.22` в
`C:\ProgramData\CodeLane\models\vosk-model-small-ru-0.22`. Модель можно скачать
с [официальной страницы Vosk](https://alphacephei.com/vosk/models).
Распознавание работает локально; запись включается только по нажатию кнопки.

### 7.1. Поддерживаемые провайдеры

| Провайдер | Ключ | Примечание |
| :-- | :-- | :-- |
| DeepSeek | `deepseek` | |

Ключи и модель задаются на вкладке **Настройки → ИИ**. Для локальных
провайдеров ключ не требуется.

### 7.2. Режимы доступа

Агент работает в одном из режимов, который ограничивает его инструменты:

| Режим | Что разрешено |
| :-- | :-- |
| **Чтение** `read_only` | Поиск, чтение файлов, анализ, git-статус |
| **Запись** `write_only` | Правка файлов без выполнения команд |
| **Полный** `full` | Чтение, правка, терминал, запуск тестов, git |

> [!WARNING]
> В полном режиме агент может выполнять команды в системе. Включайте его
> осознанно; для недоверенного кода используйте режим **Чтение**.

### 7.3. Команды чата

| Команда | Назначение |
| :-- | :-- |
| `/help` | Список команд |
| `/model [имя]` | Показать или сменить модель |
| `/models` | Модели провайдера, включая бесплатные |
| `/provider [ключ]` | Сменить провайдера |
| `/context project, file, none` | Что прикреплять к запросу |
| `/mode solve, teach` | Режим агента: решение или наставник |
| `/reasoning [уровень]` | Уровень рассуждений модели |
| `/explain` | Объяснить текущий файл |
| `/tests` | Сгенерировать тесты для файла |
| `/fix` | Найти и исправить проблемы в файле |
| `/review` | Код-ревью текущего файла |
| `/stop` | Остановить текущий ответ |
| `/clear` | Начать новый диалог |
| `/mcp` | Список MCP-серверов и инструментов |

Полный список — в `services/ai_commands.py`.

### 7.4. Упоминание файлов через `@`

В сообщении можно ссылаться на файлы проекта:

```text
@src/app/main.py объясни, почему здесь возникает ошибка
```

CodeLane подставит содержимое файла в контекст, не отправляя весь проект.

### 7.5. Инструменты агента

| Инструмент | Назначение |
| :-- | :-- |
| `find_files` | Поиск файлов по glob |

| `read_file` | Чтение фрагмента файла |
| `open_file` | Открыть файл в редакторе |
| `apply_patch` | Применить патч к нескольким файлам |
| `write_file` | Создать или перезаписать файл |
| `exec_command` | Выполнить команду в терминале |
| `run_project_tests` | Запустить тесты проекта |
| `git` | Git-команды в проекте |
| `workspace_state` | Состояние проводника, браузера и анализатора |
| `workbench_control` | Открыть панели и настройки CodeLane, управлять терминалом, сохранить или запустить файл |
| `desktop_state` | Список окон компьютера и активное окно |
| `analysis_refresh` | Обновить анализ проекта |

> Список инструментов расширяется MCP-серверами (Model Context Protocol).
> Конфигурация MCP задаётся в настройках агента.

### 7.6. Объяснение кода

Выделите код и нажмите `Ctrl+Alt+E` (или **ИИ → Объяснить код**) — откроется
диалог с разбором выделенного фрагмента. Для режима обучения доступен
**Student Explainer** с пошаговыми объяснениями.

## 8. Отложенные задачи ИИ-агента

Отложенная задача — однократный запрос обычному ИИ-агенту. Она пригодится, если
работу нужно начать позже или после появления файла в проекте. Например,
можно запланировать проверку тестов на утро или обзор отчёта после сборки.

1. Откройте проект и вкладку **ИИ-агент**.
2. В панели **Ход работы** нажмите **+** рядом с **Отложенные задачи**.
3. Укажите название, задание агенту и время **Не раньше**. По желанию укажите
   относительный путь к файлу в проекте в поле **Дождаться файла**.
4. Сохраните задачу. Двойной щелчок по ней позволяет изменить её, снять с запуска,
   возобновить или удалить.

CodeLane должен быть открыт, проект — оставаться открытым, а доступ к модели —
настроенным. Задача начнётся после указанного времени, когда агент свободен и
файл-условие существует. Если приложение закрыто, задача не выполняется; при
следующем запуске CodeLane проверит её снова. Результат появится в чате агента;
действия с файлами зависят от выбранных разрешений. Задача с ошибкой
или прерванным запуском перейдёт в состояние **Приостановлено**; для повтора
откройте её и нажмите **Запустить снова**.

Кнопка **?** рядом с заголовком показывает эти условия прямо в приложении.

## 15. Расширения

CodeLane поддерживает встроенные модули и сторонние расширения.

### Встроенные расширения

| Ключ | Название | Назначение |
| :-- | :-- | :-- |
| `browser` | Браузер | Веб-вкладки, профили и поиск |
| `todo` | To Do | Задачи проекта и личные |
| `ai` | ИИ-агент | Чат и действия в редакторе |
| `git` | Git | Управление версиями |
| `intelligence` | Анализ проекта | Метрики и граф |

Каждое можно отключить в настройках (`extension_<ключ>`).

### Сторонние расширения

Расширение — папка с манифестом `pyscribe-extension.json`. CodeLane ищет
расширения в `<проект>/.pyscribe/extensions/<имя>/` и
`extensions/installed/<имя>/`:

```json
{
  "id": "example.my-extension",
  "name": "My Extension",
  "version": "1.0.0",
  "entry": "extension.py",
  "class": "Extension"
}
```

`class` необязателен: по умолчанию загружается класс `Extension`.
Менеджер (`extensions/manager.py`) проверяет `id`, безопасно разрешает путь
к `entry` и активирует расширение. Панель **Расширения** показывает
установленные расширения и ошибки загрузки.

## 17. Настройки и темы

Все настройки собраны на одной странице (`widgets/SettingsWidget.py`) и
сохраняются в `settings.json` (в dev-режиме — `config/settings.json`,
в сборке — `%APPDATA%\\PyScribe\\settings.json`). Базовые значения берутся из
`config/settings.default.json`.

### 17.1. Основные группы

| Группа | Примеры параметров |
| :-- | :-- |
| **Оформление** | Тема, акцент, цвета фона, шрифт, размеры панелей |
| **Редактор** | Подсветка, номера строк, перенос, автосохранение, форматирование |
| **Терминал** | Размер панели и текста, плавающий терминал, подсветка вывода |
| **Проекты и сеанс** | Восстановление проекта, README, недавние, лимит истории |
| **Компиляторы** | Интерпретаторы, компиляторы и локальные СУБД, аргументы запуска |
| **ИИ-агент** | Провайдер, модель, ключ, режим доступа, MCP-серверы |
| **Браузер** | Поисковик, профиль, User-Agent |
| **Расширения** | Включение/отключение встроенных модулей |
| **Система** | Оболочка, обновления, журналирование |

### 17.2. Темы

Доступны пять тем (`design/themes.py`):

| Ключ | Название | Стиль |
| :-- | :-- | :-- |
| `dark` | Dark | Тёмная с бирюзовым акцентом |
| `midnight` | Midnight | Тёмно-синяя, тема по умолчанию |
| `graphite` | Graphite | Нейтральная графитовая |
| `nord` | Nord | Холодная северная палитра |
| `light` | Light | Светлая |

Тема меняет цвета интерфейса, редактора, панелей, терминала и подсветки кода.
Применение — мгновенное, без перезапуска.

### 17.3. Сохранение настроек

Кнопка **Сохранить** записывает изменения в `settings.json` и применяет
их на лету. Некоторые параметры (например, тема и масштаб) применяются сразу.

## 20. Диагностика

### Где искать проблемы

| Источник | Расположение |
| :-- | :-- |
| Логи приложения | `logs/` в dev-режиме; `%APPDATA%\\PyScribe\\logs` в сборке |
| Настройки | `config/settings.json` или `%APPDATA%\\PyScribe\\settings.json` |
| Отчёт о проекте | `PROJECT_REPORT.md` |
| Ошибки расширений | панель **Расширения** |

### Отправка лога

**Справка → Отправить лог…** формирует архив с логами для обращения в поддержку.

### Типичные проблемы

| Проблема | Решение |
| :-- | :-- |
| Не запускается проект | Проверьте тулчейн в настройках и `run_working_directory` |
| ИИ не отвечает | Проверьте провайдера, ключ и модель в настройках |
| Git-панель пуста | Убедитесь, что `git` установлен и проект является репозиторием |
| Не открывается БД | Проверьте драйвер СУБД и параметры подключения |
| Терминал не запускается | Проверьте доступность PowerShell/bash и настройки терминала |
